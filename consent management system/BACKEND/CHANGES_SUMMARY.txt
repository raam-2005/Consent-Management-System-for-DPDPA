═══════════════════════════════════════════════════════════════════════════
  API CHANGES
═══════════════════════════════════════════════════════════════════════════

Endpoint: POST /api/consent-requests/{id}/accept/

BEFORE:
  Request Body: (empty or optional)
  Response: ConsentRequest object

AFTER:
  Request Body: {
    "response_data": {
      "field1": "value1",
      "field2": "value2",
      ...
    }
  }
  
  Response: {
    "message": "Consent request accepted successfully",
    "consent_request": { /* full object */ },
    "consent_id": "uuid"
  }
  
  Validation:
  ├─ response_data is required
  ├─ All fields in data_requested must be provided
  ├─ User must be the designated principal
  ├─ Request must be CMS approved
  └─ Request must be in pending status

═══════════════════════════════════════════════════════════════════════════
  WORKFLOW CHANGES
═══════════════════════════════════════════════════════════════════════════

OLD FLOW:
1. Fiduciary creates request
2. CMS approves
3. Principal accepts (no data)
4. Consent created (no data stored)

NEW FLOW:
1. Fiduciary creates request with data_requested
2. CMS approves
3. Principal views request and required fields
4. Principal fills in actual data
5. Principal accepts with response_data
6. Consent created with provided_data
7. Fiduciary can access provided_data

  SUMMARY
═══════════════════════════════════════════════════════════════════════════

The consent management system has been successfully enhanced to support
a complete data collection flow where:

1. Data principals receive consent requests with specific purposes and
   data categories
   
2. Principals can view exactly what data is needed and why

3. Principals fill in the actual data for each requested field

4. Principals decide to accept (with data) or reject

5. If accepted, data is securely stored and forwarded to the fiduciary

6. All actions are audited and logged for compliance

This implementation is DPDPA 2023 compliant and provides a transparent,
user-friendly consent experience.
